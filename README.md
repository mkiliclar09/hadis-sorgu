# Hadis Sorgu

Dolaşan bir sözün hadis olup olmadığını kontrol eden arama aracı.

Kaynaklar: Buhârî, Müslim, Ebû Dâvûd, Tirmizî, Nesâî, İbn Mâce, Muvatta;
Aliyyü'l-Kârî, el-Masnû' ve el-Esrâru'l-merfû'a; Süyûtî, el-Leâli'l-masnû'a ve ez-Ziyâdât.

Site tamamen statiktir (sunucu veya veritabanı gerekmez). `index.html` sayfası `data/` klasöründeki dosyaları okur.
Türkçe çeviriler ve hüküm etiketleri yaklaşıktır; esas olan Arapça metindir.
